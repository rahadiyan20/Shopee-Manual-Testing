# Shopee-Manual-Testing

## Project Overview
This project demonstrates manual testing activities performed
on a publicly available e-commerce application.

The project was created for educational and portfolio
purposes and is not affiliated with shopee.

## Testing Scope
- Login
- Search Product
- Product Detail
- Cart
- Checkout

## User Story
**US-001-Login**
- As a user, i want to login to my account so that i can access my shopee account

**US-002-Search Product**
- As a user, i want to search product so that i can find product that i want to purchase

**US-003-Product Detail**
- As a user, i want to find a product that suits my needs

**US-004-Cart**
- As a user, i want to add products to my cart so that i can purchase them later

**US-005-Checkout**
- As a user, i want to checkout products in my cart so that i can complete my purchase 

## Acceptance Criteria##
**AC-001-Login**
- Users can login with valid credentials
- User cannot login with an incorrect password
- Users cannot login if a required field is left blank
- The system provides validation when the format is incorrect or there is an error

**AC-002-Search Product**
- Users can search for products using keywords
- The system displays relevant products
- Search can be used with an empty keyword based on the app's behavior

**AC-003-Product Detail**
- Users can chat with the seller
- Users can add more than 1 item to their cart
- Users can view product reviews
- Users can visit the sellers store profile

**AC-004-Cart**
- Users can choose which products they want to check out
- Users can remove products from their cart
- Users cannot check out if they haven't selected a product yet
- Users can choose which voucher to use

**AC-005-Checkout**
- Users can enter their shipping address
- Users can choose the shipping method
- Users can choose a payment method
